# 🧠 Alzheimer's Disease Detection Using Deep Learning

A deep learning-based system for detecting and classifying stages of Alzheimer's disease from MRI brain images using **DenseNet121**.

The project uses a convolutional neural network to classify MRI images into four different stages and provides visual explanations using **Grad-CAM**.

## 📌 Project Overview

Alzheimer's disease is a progressive neurological disorder that affects memory and cognitive functions.

This project aims to assist in the classification of Alzheimer's disease stages from MRI brain images using deep learning.

A **DenseNet121** model was trained using MRI images and used to classify images into four categories:

* **No Impairment**
* **Very Mild Impairment**
* **Mild Impairment**
* **Moderate Impairment**

The project also uses **Grad-CAM (Gradient-weighted Class Activation Mapping)** to visualize the regions of the MRI image that contributed to the model's prediction.

## ✨ Features

### 1. Alzheimer's Stage Classification

The trained DenseNet121 model predicts the Alzheimer's disease stage from an uploaded MRI image.

The model classifies the input into one of four categories:

```text
No Impairment
Very Mild Impairment
Mild Impairment
Moderate Impairment
```

### 2. Deep Learning Model

The project uses **DenseNet121**, a convolutional neural network architecture designed for image classification.

The model was trained using MRI brain images resized to:

```text
224 × 224 pixels
```

### 3. Grad-CAM Visualization

Grad-CAM is used to generate a heatmap showing the areas of the MRI image that had a greater influence on the model's prediction.

This provides a visual interpretation of the model's decision rather than showing only the predicted class.

### 4. Model Evaluation

The model was evaluated using multiple classification metrics, including:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

### 5. Flask Backend

A Flask backend is used to handle image uploads and model prediction requests.

The prediction workflow includes:

```text
Upload MRI Image
       ↓
Image Preprocessing
       ↓
DenseNet121 Model
       ↓
Predicted Class
       ↓
Grad-CAM Visualization
       ↓
Prediction Result
```

## 🧠 Model Architecture

The project uses **DenseNet121** as the primary deep learning architecture.

The input MRI image is resized to `224 × 224` and passed through the trained model.

The model produces a prediction corresponding to one of the four Alzheimer's disease categories.

## 📊 Classification Categories

| Class                | Description                                   |
| -------------------- | --------------------------------------------- |
| No Impairment        | MRI image classified as showing no impairment |
| Very Mild Impairment | MRI image classified as very mild impairment  |
| Mild Impairment      | MRI image classified as mild impairment       |
| Moderate Impairment  | MRI image classified as moderate impairment   |

## 🔥 Grad-CAM

Grad-CAM is used to improve the interpretability of the deep learning model.

Instead of displaying only the predicted class, the system generates a heatmap that highlights image regions that contributed strongly to the prediction.

This helps provide a visual explanation of the model's output.

## 🚀 Application Workflow

1. Upload an MRI brain image.
2. The image is preprocessed and resized.
3. The trained DenseNet121 model processes the image.
4. The model predicts the Alzheimer's disease category.
5. Grad-CAM generates a heatmap for model interpretation.
6. The prediction and visualization are displayed to the user.
